**Task Furnace** is an always-on orchestration engine that automates AI-driven software development workflows. It continuously picks up development tasks, assigns them to specialized AI agents one by one, executes in a loop, and tracks progress.

**Key Features:**
- Persistent background service for task queue management
- Continuous task assignment to AI agents
- Progress tracking
- Hot reload development mode

**Tech Stack:**
- Bun v1.3.9+ (runtime)
- TypeScript
- Node.js project structure with standard tooling (linting, formatting, testing)
